# Repository reduction and audit

This snapshot preserves active research source and input/checkpoint files byte-for-byte from the latest 18-case archive. It is not an algorithm rewrite.

## Scope

- Source archive: **332 files** (58.8 MB uncompressed).
- Retained files from that archive: **101** (23.1 MB uncompressed).
- Removed from active tree: **231** files.
- Also added: README, `run.py`, `.gitignore`, this report and checksum manifest.
- Earlier V3 and deterministic archives were exact subsets of the newest 18-case archive, with unchanged shared contents.
- The separate extended training bundle (73 historical/QA files, ~119 MB uncompressed) was not merged. The three canonical runtime development CSVs remain in `forecast_release/.../data/`.

## Excluded material by category

- **forecast_release** — 133 files. Unused alternative source releases, copula comparison checkpoints, duplicated datasets, old reports and forecast QA outputs.
- **<root>** — 70 files. Superseded launchers, migration scripts and patch-history/hand-over notes.
- **cvae_v2_diagnostics** — 11 files. Legacy CVAE diagnostic exports.
- **forecast_diagnostics_continuous_v3** — 5 files. Previously generated CVAE plots/metrics and demonstration scenario outputs.
- **tests** — 4 files. Obsolete tests for removed migration scripts/fixed-bid patch or missing generated demonstration outputs.
- **fixed_bid_ablation_reference** — 3 files. Fixed-bid exploratory ablation outputs, outside frozen study matrix.
- **figures** — 2 files. Previously generated plots; figures can be recreated from the active experiment code.
- **forecast_diagnostics_2025** — 2 files. Old model evaluation exports.
- **baseline_reference** — 1 files. Historical fixture README replaced by focused test fixture.

## Validation

- Original source and model/data files retained in this repository are byte-identical to the input archive, with individual SHA-256 digests in `SOURCE_MANIFEST.json`.
- Both preflights passed *without* invoking Gurobi, including causal hour/context checks, sampled continuous CVAE and six study windows.
- Original deterministic one-scenario model smoke checks passed using SciPy HiGHS.
- **78 regression tests passed** on this curated tree. Removed historical migration tests were not silently edited: tests tied to removed historical utilities or absent demonstration-result folders were excluded.
- Full Gurobi HL+LL weeks have **not** been rerun here; they require the user’s working Gurobi licence and time.

## Known limitations and publishing

- Scientific source structure is intentionally not refactored because runners rely on relative paths, imports and code/data checksums.
- Some launcher code modifies imported modules in-process. The added `run.py` uses fresh interpreter processes for each campaign and for two distinct preflights.
- This is a frozen replay/inference repository with core training definitions, *not* complete source-data ETL or raw data downloads.
- Wind/price CSV redistribution permissions and code licensing must be reviewed before hosting publicly.
- The existing `stochastic_v3_reference` CSVs are retained for the original deterministic-vs-stochastic comparator, but are historical reference outputs rather than current experiment scores.
